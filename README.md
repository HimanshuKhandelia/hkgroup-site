# Himanshu Khandelia Group website

A simple Quarto website intended to replace the legacy WordPress site at `hkgroup.sdu.dk`.

## Navigation

- Research
- Group Members → Present / Past
- Publications
- Simulation Highlights
- News
- Open Positions
- Teaching
- Funding
- Contact

## Maintenance philosophy

Content is Markdown. There is no WordPress database and no theme/plugin maintenance. Publications are generated automatically from PubMed during deployment. GitHub Actions renders and deploys the site to GitHub Pages on every push to `main`.

See `EDITING_GUIDE.md` for routine updates.
